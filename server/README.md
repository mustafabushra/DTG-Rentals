# نقطة النهاية — قراءة العقود

دالة واحدة تقرأ صورة عقد وتُرجع بياناته منظَّمة. تسكن **خارج التطبيق** لأنها
تحمل مفتاح API مدفوعاً، ومفاتيح كهذه لا يجوز أن تكون في حزمة الويب — يقرؤها أي
أحد يفتح أدوات المطوّر.

## لماذا خادم أصلاً؟

العقود صور عربية. لا يوجد مسار على الجهاز يعطي دقة مقبولة: Tesseract ضعيف مع
العربية، وML Kit لا يدعمها، وVision على iOS فقط بينما تطبيقك ويب أولاً. فالقراءة
تحتاج نموذجاً بصرياً، والنموذج يحتاج مفتاحاً، والمفتاح يحتاج خادماً.

## ما تحتاجه

- حساب [Vercel](https://vercel.com) (الطبقة المجانية تكفي)
- مفتاح Anthropic من [console.anthropic.com](https://console.anthropic.com)

## النشر

```bash
cd server
npx vercel          # أول مرة: يسألك عن المشروع
npx vercel --prod
```

ثم اضبط متغيّرات البيئة من لوحة Vercel أو:

```bash
npx vercel env add ANTHROPIC_API_KEY production
npx vercel env add FIREBASE_PROJECT_ID production     # dtg-rentals
npx vercel env add ALLOWED_ORIGIN production          # https://dtg-rentals.web.app
```

**لا تضع المفتاح في أي ملف داخل المستودع.** متغيّرات Vercel تسكن عندهم مشفَّرة.

أعد النشر بعد ضبط المتغيّرات (`npx vercel --prod`) حتى تُقرأ.

## ربطه بالتطبيق

في `.env.local` بجذر المشروع:

```
EXPO_PUBLIC_CONTRACT_SCAN_URL=https://<مشروعك>.vercel.app/api/extract-contract
```

هذا الرابط **علني آمن** — لا يعمل بلا رمز هوية Firebase صالح. ولأنه
`EXPO_PUBLIC_*` يُحزَم في الويب، فأضِفه أيضاً إلى أسرار GitHub Actions إن أردت
النشر التلقائي.

بلا هذا المتغيّر يعرض التطبيق شاشة «الميزة غير مهيّأة» ولا يتعطّل.

## العقد

```
POST /api/extract-contract
Authorization: Bearer <firebase id token>
{ "imageBase64": "...", "mimeType": "image/jpeg" }

200 { "ok": true,  "extraction": { tenantName, startDate, annualValue, ... } }
4xx { "ok": false, "code": "...", "message": "رسالة عربية للمستخدم" }
```

| الرمز | المعنى |
|---|---|
| `UNAUTHORIZED` | رمز الهوية غير صالح أو منتهٍ |
| `RATE_LIMITED` | تجاوز الحد (30 قراءة/ساعة لكل مستخدم) |
| `IMAGE_TOO_LARGE` | أكبر من 5 ميجابايت |
| `BAD_MIME` | نوع صورة غير مدعوم |
| `UNREADABLE` | النموذج لم يُرجع JSON صالحاً |
| `UPSTREAM` | عطل أو ازدحام عند المزوّد |
| `NOT_CONFIGURED` | متغيّرات البيئة ناقصة |

## الحمايات

**التحقق من الهوية** — رمز Firebase يُتحقَّق منه بشهادات Google العامة: الخوارزمية
والجمهور والمُصدِر والانتهاء والتوقيع. بلا هذا تصير البوّابة مفتوحة لمن يجد الرابط.

**حدّ المعدل** — 30 قراءة في الساعة لكل **مستخدم** (لا لكل عنوان IP، فالعدل بين
المستخدمين). *حدّ معروف:* الذاكرة لكل نسخة من الدالة، والمنصّات بلا حالة تُشغّل
نسخاً متعددة، فالحدّ الفعلي قد يصل إلى (30 × عدد النسخ). مقبول كطبقة أولى مع حدّ
الحجم والتحقق من الهوية؛ الحدّ الصارم يلزمه مخزن مشترك وهو تعقيد لا يستحقه
الاستخدام الحالي.

**حدّ الحجم** — يُرفض قبل أي استدعاء مدفوع، فالصورة الضخمة لا تكلّفك شيئاً.

**CORS** — اضبط `ALLOWED_ORIGIN` ليقتصر على نطاقك.

## حدود القراءة نفسها

النموذج يُطلب منه أن ينقل القيم **كما هي** بلا تحويل: لا يحوّل الهجري إلى ميلادي،
ولا الأرقام العربية، ولا يضرب الإيجار الشهري في 12. كل ذلك يتولّاه
`ContractExtractionService` في التطبيق حيث هو مختبَر.

والقراءة **تقترح ولا تكتب**: النتيجة تُعرض في شاشة مراجعة تؤكّدها بنفسك. خطأ
قراءة صفر واحد يضاعف الإيجار عشر مرات، ولهذا لا تُحفظ قيمة بلا عين بشرية.
